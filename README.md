# 🚗 Rider Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing ride-sharing data using SQL to understand ride patterns, driver performance, customer activity, vehicle details, and ratings.

## 🎯 Objectives
- Analyze ride and driver performance.
- Understand customer ride activity.
- Explore vehicle information and availability.
- Analyze ratings and ride experiences.
- Generate insights to support better business decisions.

## 🛠️ Tools & Technologies
- **SQL**
- **MySQL Workbench**
- **CSV Datasets**
- **GitHub**

## 📂 Project Structure
- `Riders Project.sql` – SQL queries used for data analysis.
- `drivers.csv` – Driver information.
- `ratings.csv` – Ride rating information.
- `rides.csv` – Ride details.
- `users.csv` – User information.
- `vehicles.csv` – Vehicle details.

## 📊 Key Analysis Areas
- Ride and revenue analysis
- Driver performance analysis
- User activity analysis
- Vehicle analysis
- Rating analysis
- SQL JOINs and aggregate functions

## 💡 Business Value
The analysis helps identify ride patterns, understand driver performance, evaluate customer experiences, and support data-driven decisions in ride-sharing operations.
